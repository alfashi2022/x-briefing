手动刷新

X 简报

登录后添加要跟踪的账号。点击「刷新」后，显示最近 7 天的发言，原文和简体中文并排。

注册或登录后，关注的账号和上次简报只属于这个账号。退出后再打开，不会看到别人的列表。

    近 7 天

    还没有账号

    请添加一个 X 账号（可带或不带 @）。

    可选设置

    默认不用密钥。公开嵌入时间线约每段时间 30 次请求；这台机器上它经常被限流，刷新会改用 FxEmbed 的公开只读接口。

    如果要改走 X 官方 API v2，在 developer.x.com 创建应用，复制 Bearer Token 后保存。免费套餐可能没有读取时间线的权限。Token 保存在你的账号里，页面不会再显示它。

    关注的账号和上次简报保存在你的账号里。换一个账号登录会看到另一份列表。点击「刷新」才会重新获取发言。

    翻译为简体中文，来自 Google 的免费翻译接口；失败时改用 MyMemory。翻译失败会写明原因，页面不会编造译文。
