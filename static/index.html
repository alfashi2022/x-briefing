手动刷新

X 简报

添加要跟踪的账号。点击「刷新」后，每条发言并排显示原文和简体中文。

    还没有账号

    请添加一个 X 账号（可带或不带 @）。

    可选设置

    默认不用密钥。公开嵌入时间线约每段时间 30 次请求；这台机器上它经常被限流，刷新会改用 FxEmbed 的公开只读接口。

    如果要改走 X 官方 API v2，在 developer.x.com 创建应用，复制 Bearer Token 后保存。免费套餐可能没有读取时间线的权限。Token 只写在本机文件里，页面不会再显示它。

    账号保存在本机 data/accounts.json，刷新页面后仍然在。点击「刷新」才会重新获取发言。

    翻译为简体中文，来自 Google 的免费翻译接口；失败时改用 MyMemory。翻译失败会写明原因，页面不会编造译文。
